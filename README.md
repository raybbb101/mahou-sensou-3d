# 魔法戦争 3D

3Dドット絵(スプライトスタッキング)で描いた魔法のローグライク。2つのモード、ソロと最大4人の協力プレイ。

**遊ぶ:** https://raybbb101.github.io/mahou-sensou-3d/

スマホは Chrome で開いて「アプリをインストール」(iPhone は Safari の共有 →「ホーム画面に追加」)すると、全画面・横向きで遊べます。ソロはオフラインでも動きます。

## 2つのモード

### 迷宮モード(探索)

部屋と通路でできた迷宮を自由に歩き回るモード。「ふたつの灯 v2.5」を参考にしています。

- キャラクターは4人: **剣士**(長剣・戦鎚・槍) / **弓使い**(長弓・連弩) / **魔導士**(魔杖・魔導書) / **召喚師**(使い魔・精霊・ゴーレムを呼ぶ。自分では攻撃しない)
- 宝箱から武器が出る。レア度は5段階(コモン〜レジェンド)で、レア度が高いほど特殊効果(炎・氷・吸血・疾風・必殺)が付く。今の武器より強ければ自動で装備、弱ければ経験値に変わる
- 敵を倒すと経験値が入り、レベルが上がると HP・攻撃力・魔法のランクが上がる。精鋭(金色に光る敵)は武器を落とすことがある
- 最奥のボスを倒すと**ゲート**が開く。全員でゲートに入ると次のステージへ。全10ステージ
- 協力プレイで倒れた仲間は、そばに2秒立つと起こせる

### 塔モード(ボス連戦)

円形の闘技場で10体のボスと戦うモード。「魔法戦争 v1」を3Dにしたもの。

- 各層のはじめに魔法を1つ選ぶ(同じ魔法でランクアップ、最大4つ)
- ボスを倒すと強化を1つ選ぶ。全滅すると第1層から

## 魔法は3段階

| 段階 | 例 | 見た目 |
|---|---|---|
| 基本 | ファイアボール、アイスシャード、旋風斬、拡散射 | 弾や小さな爆発 |
| 上級 | メテオ、サンダーストーム、ブラックホール、地裂斬、矢の雨 | 空から岩が落ちる、雷、渦、地面を走る炎 |
| 究極 | 天墜・紅蓮メテオ、絶対零度、神鳴・百雷、聖天の審判、虚無の顎、風神降臨 | 時が止まり、カメラが回り込むカットシーン付き |

## 操作

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | WASD / 矢印 | 画面左側をドラッグ |
| 攻撃 / 魔法 | J(押しっぱなしで連続) K L I、または 1〜4 | 右下のボタン |
| 回避 | Space | 回避ボタン |
| 究極魔法 | E | 究極ボタン(溜まると光る) |
| 一時停止 / 消音 | Esc / M | 右上 |

魔法と攻撃は一番近い敵を自動で狙います。

## 協力プレイ

「仲間と挑む」でモードを選んで部屋を作ると5文字のコードが出ます。仲間は同じページを開いてコードで入ります。
PeerJS(WebRTC)でブラウザ同士を直接つなぐのでサーバーは要りません。戦闘は部屋を作った人のブラウザで計算します。

## しくみ

ビルド不要の静的サイトです(ES モジュール)。

- `src/sim/` ゲームの計算(描画に依存しない)。`world.js` 塔モードの戦闘、`dungeon.js` 迷宮の生成と迷宮モードの戦闘(World を継承)、`session.js` 進行、`data.js` 魔法・キャラ・武器・ボスの表
- `src/render/` 描画。`voxel.js` ボクセル → スライス → 角度ごとのスプライトのキャッシュ、`models.js` すべてのモデル(コードで作ったボクセル)、`view.js` カメラ・床・壁・魔法・カットシーン、`fx.js` 粒子と光
- `src/ui/` メニューと HUD、`src/net/p2p.js` 協力プレイ

軽さのために、モデルは角度ごとに一度だけ描いてキャッシュし、毎フレームは `drawImage` を重ねるだけにしています。光は加算合成の光の玉です。

手元で動かす:

```bash
python3 -m http.server 8080
```

`node tools/simtest.mjs` はブラウザなしで両モードをボットで進める確認用です。

エフェクトの作り方(段階的な色のランプ、ディザ、光の層)は [pixelfx](https://github.com/patch-gg/pixelfx)、スプライトスタッキングは sprite-stack-3d の方法を元にしています。
